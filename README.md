# WAVE LAB · 영의 이중슬릿 실험실

설치할 외부 패키지 없이 동작하는 한국어 인터랙티브 실험입니다.

## 실행

```sh
cd /workspace/gpt_test
npm start
```

브라우저에서 실행한 서버의 8000번 포트로 접속합니다. ES 모듈을 사용하므로 HTML 파일을 직접 열지 말고 HTTP 서버로 실행하세요. Python 3와 Node.js 18 이상이 있으면 실행 및 검증할 수 있습니다.

```sh
npm test
```

## 사용

- 두 슬릿, 한 슬릿, 완전한 경로 검출, 단일 광자 상황 선택
- 파장, 슬릿 간격, 슬릿 폭, 스크린 거리 및 재생 속도 조절
- 일시정지, 한 단계 시간 진행, 누적 기록 초기화
- 아래 네 과정 카드를 눌러 방출·회절·중첩·검출 과정 확인
- 3D 장치 보기에서 드래그로 회전, 휠로 확대/축소

## 물리 모형 및 한계

원거리(Fraunhofer) 회절에서 `I ∝ sinc²(πa sinθ/λ) cos²(πd sinθ/λ)`, `sinθ = y / √(L²+y²)`를 사용합니다. a는 슬릿 폭, d는 중심 간격입니다. 한 슬릿과 완전한 경로 검출에서는 간섭항을 제거합니다. 그래프는 각 상황의 최대 세기를 1로 정규화하므로 상황 사이 절대 광량 비교용이 아닙니다. 검출 점은 ±20 mm 범위에서 조건부 정규화한 확률 분포로 추출합니다. 막대 분포는 현재 최대 빈도를 기준으로 정규화합니다.

3D 장치와 2D 파면은 개념도이며 실제 길이·시간 축척이 아닙니다. 파장·간격·폭·거리는 이론 분포에 정량적으로 적용됩니다. 경로선은 광자의 실제 궤적을 묘사하지 않습니다. 경로 검출은 사람의 관찰 자체가 아니라 환경 또는 검출기와의 상호작용으로 경로 정보가 완전히 구별되는 이상적 조건입니다. 근거리 회절, 편광, 부분 결맞음, 실제 검출기 손실은 포함하지 않습니다.
